# Prompt Forge App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the approved Prompt Forge identity, derive all native and web icon formats, and connect them to Prompt Editor's macOS, Windows, Linux, and website entry points.

**Architecture:** Keep one reviewed 1024 px raster master plus two focused SVG brand sources: a monochrome tray mark and a horizontal website lockup. A deterministic shell script uses macOS `sips` and `iconutil` for PNG and ICNS output, while a focused Swift/ImageIO utility assembles the multi-representation ICO; a separate validation script checks paths, dimensions, embedded representations, transparency, and integration references.

**Tech Stack:** SVG, PNG, `sips`, `iconutil`, POSIX shell, Swift/AppKit, Rust/GTK4, Tauri configuration, HTML/CSS

---

## File Map

- `assets/branding/prompt-forge-1024.png`: reviewed full-color master artwork.
- `assets/branding/prompt-forge-tray.svg`: monochrome source for menu bar and tray derivatives.
- `assets/branding/prompt-editor-lockup.svg`: horizontal website brand lockup.
- `scripts/generate-icons.sh`: deterministic native and web derivative generation.
- `scripts/make-ico.swift`: focused ImageIO utility that packs 16, 32, 48, 128, and 256 px PNG inputs into one ICO.
- `scripts/validate-icons.sh`: asset and configuration contract checks.
- `macos/PromptEditor/Resources/PromptEditor.icns`: macOS bundle icon.
- `macos/PromptEditor/Resources/StatusBarIcon.png` and `StatusBarIcon@2x.png`: macOS template images.
- `windows/icons/*`: Tauri application and tray files already named in `windows/tauri.conf.json`.
- `linux/icons/hicolor/*/apps/prompt-editor.png`: freedesktop-size Linux assets.
- `website/assets/brand/*`: favicon, touch icon, standalone mark, and lockup copies.
- `macos/PromptEditor/Info.plist`, `macos/PromptEditor/StatusBarItem.swift`, `Makefile`, `build.sh`: macOS references and packaging.
- `linux/src/main.rs`, `Makefile`, `build.sh`: Linux icon-name selection and desktop packaging.
- `website/index.html`, `website/features.html`, `website/download.html`, `website/assets/style.css`: web head metadata and navigation lockup.
