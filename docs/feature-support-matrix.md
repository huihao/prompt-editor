# Prompt Editor 功能与平台支持矩阵

本文档记录当前版本面向用户的主要功能、实现完整度和平台支持情况。

## 评价标准

- **高**：主流程已实现，并有一定测试覆盖。
- **中**：基本可用，但存在平台限制、错误处理或体验缺口。
- **低**：只有 MVP、模拟数据、实验性实现或仅部分平台接通。
- **未完成**：代码占位、桥接未实现，或当前无法构建验证。

平台标记：

- **M**：macOS
- **W**：Windows
- **L**：Linux
- `*`：代码存在，但当前构建或桥接仍有问题

## 当前产品策略

当前版本暂时隐藏“发送到终端”功能，仅提供复制到剪贴板和“粘贴到上次位置”作为提示词输出方式。发送目标选择器、Agent 刷新按钮、发送确认弹窗和发送快捷键均已关闭；底层发送代码保留，待跨平台桥接和成功确认机制完善后再恢复。

## 平台成熟度结论

| 平台 | 当前判断 |
| --- | --- |
| macOS | 正式支持；编辑、发送、Agent 检测、Prompt Memory、终端集成及 Universal 2 发布流程可用；数据迁移仍需加强 |
| Windows | UI 和部分 Tauri 代码存在，但当前依赖无法构建，前端桥接也未完成，不能视为可用版本 |
| Linux | GTK 依赖无法解析，Wayland 未实现，文件、终端和 Prompt Memory 能力明显不完整 |
| 纯 Web/编辑器层 | 编辑、历史、模板、Snippet、部分 AI 功能可以运行，但文件和终端能力需要原生桥接 |

## 当前版本建议定位

当前更适合定位为：

> macOS 优先的实验性 Prompt Editor，Windows/Linux 支持处于预览阶段。

开源发布时不建议在 README 中把三个平台描述成同等成熟度。
